# VoiceBridge

VoiceBridge is a local-first voice-command workbench for coding agents. The current MVP records audio, transcribes through local faster-whisper, optionally refines text through a user-configured OpenAI-compatible API, then requires review before copying to the clipboard.

See the Chinese [README](README.md) for installation, limits, privacy details, and verified test scope. No Coding Agent is automatically controlled in this release.
